# Unit M2.2 — The 2026 AI Stack

*Week 11*

## Topics

### Foundation models

- Trained once at scale, usable for many tasks

### Fine-tuning

- Adapting a model on smaller domain-specific data

### RAG (concept)

- Giving AI external knowledge at query time

### Agents (concept)

- LLM + memory + tools + planning loop

### Tool use

- AI calling search, calculator, code runner

### Multimodal AI

- Text, image, audio, video in one system

## Labs

**Lab M2.2a: Tool scorer** — Score two AI tools across five criteria and print each criterion with both scores side by side.

**Lab M2.2b: Weighted scoring** — Assign weights summing to 1.0, compute weighted scores, and print the weighted winner.

**Lab M2.2c: Rubric as a dictionary** — Represent the rubric as a dict and write `score_tool(rubric, scores)` returning the weighted total.

**Lab M2.2d: Comparison report** — Write `compare_tools(...)` printing a full comparison table and declaring a justified winner.
