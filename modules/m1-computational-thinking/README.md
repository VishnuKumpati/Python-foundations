# M1 · Computational Thinking

**AI Module 1** · Week 8 (kickoff) – Week 9 · 6 hrs

**Builds on:** Part A (P1–P6) — a working Python and Git baseline

The gentle on-ramp into AI thinking for learners who now have Python basics. Before touching any model, learners learn to think computationally — decompose, abstract, spot patterns, and above all write clear specifications. In an AI-native workflow the human specifies and verifies while AI implements; this module builds that specifying muscle.

## Learning Outcomes

By the end of this module, learners can:

- Decompose a domain problem into a task tree and abstract at the right level
- Express logic as pseudocode and flowcharts, then translate to code
- Write testable, bounded, observable specifications
- Judge when AI is and is not the right tool for a task

## Scope

**In scope:** Computational-thinking skills; flowcharting and pseudocode; specification writing; the 70/30 specify-and-verify model

**Out of scope:** Formal algorithm complexity analysis; building any AI system (comes later)
